# How to start? Method 1: Jupyter

Method 1: jupyter-based

- Step 1: install anaconda;
- Step 2: unzip `day1_python_intro.zip`;
- Step 3: go to `path/to/day1_python_intro` in cli;
- Step 4: type `jupyter notebook`.

# How to start? Method 2: VSCode

Method 2: vscode-based

- Step 1: install anaconda;
- Step 2: unzip `day1_python_intro.zip`;
- Step 3: start vscode
- Step 4: install plugin for python & jupyter ;
- Step 5: open folder `path/to/day1_python_intro`
